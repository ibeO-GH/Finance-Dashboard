# Finance Dashboard

A clean and modern finance dashboard for tracking income, expenses, and balances with a focus on simplicity and usability.

## 🚀 Features

- Income and expense tracking
- Real-time balance updates
- Clean card-based UI
- Responsive layout
- Simple and intuitive user experience

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS

## 📦 Installation

```bash
npm install
npm run dev
```

## 🏗️ Build

```bash
npm run build
```
